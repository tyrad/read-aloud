# Edge TTS Quick Start

## 🎯 What You Get

Free, high-quality Microsoft Edge neural voices without any API key:
- ✅ **26+ voices** for Chinese and English (100+ when online)
- ✅ **Works immediately** - No configuration needed
- ✅ **Oct 2026 DRM fix** - Fully functional with latest Microsoft requirements

## 📦 Installation (2 minutes)

### Option 1: Load Unpacked Extension

```bash
# Clone this repository
git clone https://github.com/tyrad/read-aloud.git
cd read-aloud

# Switch to Edge TTS branch
git checkout cursor/add-edge-tts-support-8809

# Optional: Package for distribution
npm install
npm run package -- --browser=chrome
# Creates: build/read-aloud-chrome-2.25.0.zip
```

**Load in Chrome/Edge:**
1. Open `chrome://extensions` (or `edge://extensions`)
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the `read-aloud` directory

**Or install the packaged version:**
1. Drag `build/read-aloud-chrome-2.25.0.zip` onto `chrome://extensions`
2. Click "Add extension"

### Option 2: Firefox

```bash
npm run package -- --browser=firefox
```

Then in Firefox:
1. Navigate to `about:debugging`
2. Click "This Firefox"
3. Click "Load Temporary Add-on"
4. Select `manifest.json` from the repository

## 🔧 Troubleshooting

### No Edge Voices Appear

**Check browser console** (F12 → Console):
```javascript
// Test token generation
edgeTtsEngine.generateSecMsGecV2(1729900000.0)
// Expected: "8350A5B1232C2B03-103B2FE3AC01F6E41589E122B054FEAA29908FF87A67426A52501CBAD60BCE89"

// Test voice loading
edgeTtsEngine.getVoices().then(v => console.log(`${v.length} voices`))
// Expected: 26 or more voices
```

**Fallback voices**: Even if the API fails, 26 default voices should appear.

### Audio Doesn't Play

1. Check voice is selected (Settings → Voice → starts with "Edge")
2. Test with browser native voice first (confirm Read Aloud works)
3. Check browser console for errors
4. Verify internet connection (Edge TTS requires network)

### 403 or 404 Errors

This means the DRM token isn't working. Verify:
1. You're on the `cursor/add-edge-tts-support-8809` branch
2. Latest commits include "Fix Edge TTS: Add Sec-MS-GEC v2"
3. Token generation test passes (see console test above)

## ⚠️ Important Notes

1. **Unofficial Service**: This uses Microsoft Edge's Read Aloud endpoint
   - May stop working if Microsoft changes the service
   - No service level agreement (SLA)
   - For personal, non-commercial use

2. **DRM Protection**: As of Oct 2026, Microsoft requires cryptographic tokens
   - This fork implements the required DRM (Sec-MS-GEC v2)
   - Tokens are generated client-side in your browser
   - No external servers or services involved

3. **Internet Required**: Edge TTS synthesis requires network connection
   - Voice list fetched from Microsoft servers
   - Audio generated by Microsoft's cloud service
   - Cached locally after first synthesis
